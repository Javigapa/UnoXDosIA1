🗂️ Secciones por JORNADA (se añaden acumulando, una debajo de la otra)

Cómo funciona: Cada vez que termina una jornada, el admin genera el HTML de esa jornada. Tú lo añades DENTRO del contenedor de la sección, en el bloque de comentarios de esa jornada específica. Las jornadas anteriores quedan visibles debajo del desplegable.
📰 Crónicas — por jornada por jornada

Admin → pestaña 📰 Crónicas → selecciona jornada → asigna → "Generar HTML crónicas"

<div class="cronicas-grid" id="cronicas-grid"> <!-- CRONICAS_J1_HTML --> [pega aquí el HTML de crónicas de Jornada 1] <!-- /CRONICAS_J1_HTML --> <!-- CRONICAS_J2_HTML --> [pega aquí el HTML de crónicas de Jornada 2] <!-- /CRONICAS_J2_HTML --> <!-- ... y así hasta la J14 --> </div>
Selector del usuario: El desplegable de jornada en la web leerá los comentarios para mostrar las crónicas de la jornada seleccionada.

⚙️ JS que necesitas añadir a fantas-ia-v2.html

Selector de jornada para Crónicas, XI, Análisis y Puntos

Añade este bloque de JS al final de tu <script> en fantas-ia-v2.html. Lee los comentarios HTML del archivo y muestra/oculta las secciones según la jornada seleccionada.

// ── SELECTOR DE JORNADA (Crónicas, XI, Análisis, Puntos) ── // Mapeo: id del select → prefijo del comentario → id del grid contenedor const JORNADA_SECCIONES = [ { sel: 'sel-jornada-cronicas', prefix: 'CRONICAS', grid: 'cronicas-grid' }, { sel: 'sel-jornada-xi', prefix: 'XI', grid: 'xi-grid' }, { sel: 'sel-jornada-analisis', prefix: 'ANALISIS', grid: 'analisis-content' }, { sel: 'sel-jornada-puntos', prefix: 'PUNTOS', grid: 'puntos-jornada-grid'}, ]; function mostrarJornada(prefix, grid, jornada) { const container = document.getElementById(grid); if (!container) return; const children = Array.from(container.children); children.forEach(el => { // Mostrar todos si no hay jornada seleccionada if (!jornada) { el.style.display = ''; return; } // Buscar a qué bloque pertenece este elemento // Los bloques están delimitados por comentarios // Necesitamos recorrer los nodos del DOM incluyendo comentarios }); // Estrategia: usar atributo data-jornada en el HTML pegado // Alternativa más robusta: ocultar todo y mostrar solo el bloque correcto const allBlocks = container.querySelectorAll('[data-jornada]'); if (allBlocks.length) { // Si el HTML pegado tiene data-jornada="N" allBlocks.forEach(b => { b.style.display = (!jornada || b.dataset.jornada == jornada) ? '' : 'none'; }); } } JORNADA_SECCIONES.forEach(sec => { const sel = document.getElementById(sec.sel); if (sel) sel.addEventListener('change', () => mostrarJornada(sec.prefix, sec.grid, sel.value)); });
Alternativa más sencilla: Añade data-jornada="1" a cada bloque de jornada cuando lo pegas. El JS de arriba ya lo leerá automáticamente. Por ejemplo, el admin ya genera los bloques con ese atributo en la versión actualizada.

✅ Flujo de trabajo por jornada

Cada jornada, en orden:
1. Admin → ⚽ Resultados → introduce goles → Guardar → Generar HTML jornadas → pegar en JORNADAS_HTML
2. Admin → 🏆 Clasificación → actualiza datos → Generar filas → pegar en los tbody
3. Admin → 🎲 Dados → tira los dados
4. Admin → 📊 Puntos → selecciona jornada → rellena puntos → Generar HTML → pegar en PUNTOS_JN_HTML
5. Admin → 📰 Crónicas → selecciona jornada → escribe → asigna → Generar HTML → pegar en CRONICAS_JN_HTML
6. Admin → ⚽ XI Ideal → selecciona jornada → rellena → Generar HTML → pegar en XI_JN_HTML
7. Admin → 🔍 Análisis → selecciona jornada → escribe → Generar HTML → pegar en ANALISIS_JN_HTML
8. Si hubo mercado: Admin → 💰 Mercado → Generar HTML subasta + Plantillas → pegar en ambos sitios
